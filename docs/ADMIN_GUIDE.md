# 管理员手册

## 角色

- **admin**：查看全部记录、全站统计、用户管理、额度调整、AI 使用量；AI 无个人上限（仍受全站每日上限约束）。
- **member**：只能查看和管理自己的记录；受每日额度（默认 20）与全站上限（默认 200）约束。

## 管理入口

登录后导航栏「管理」。非管理员访问相关接口一律 403（前端与后端双重校验，以后端为准）。

## 创建用户

「创建用户」面板：用户名（3-32 位字母/数字/下划线）+ 初始密码（≥8 位）+ 角色 + 可选每日额度（留空 = 默认 20）。

创建后把初始密码线下告知对方；对方可在使用中更换（当前版本由管理员重置密码实现换密）。

## 邀请码（推荐的受邀方式）

1. 「邀请码」面板点「生成一次性邀请码」。
2. 把 `TQ-XXXXXXXX` 码 + 站点访问密钥线下发给受邀人。
3. 受邀人在登录页点「使用邀请码激活账号」，填码、站点密钥、自选用户名和密码，一步激活。
4. 码使用一次后自动作废（状态 `redeemed`），面板可见完整状态列表。

无公开注册：没有邀请码或管理员操作，任何人无法创建账号。

## 调整额度

「用户管理」表格 → 「调额度」：

- 输入数字：该用户每日 AI 解读次数上限（0-10000）
- 留空提交：恢复默认 20
- 管理员账号个人不受额度限制

全站每日上限存在 D1 `settings` 表（键 `global_daily_ai_limit`，默认 200）。修改方式（Cloudflare 控制台 → Storage & Databases → D1 → tarot-astrology → Console）：

```sql
UPDATE settings SET value = '300' WHERE key = 'global_daily_ai_limit';
```

额度每日 Asia/Shanghai 午夜自动重置，无需手工操作。

## 重置密码

「用户管理」→「重置密码」：输入新密码（≥8 位）后，该用户所有登录会话立即失效，下次登录需用新密码，系统会提示其尽快改密。

## 停用 / 启用用户

停用后该用户立即无法登录、现有会话全部失效，记录保留。管理员无法停用自己或修改自己的角色（防止锁死）。

## 查看全站用量

「统计」页管理员区域：全站解读总数、今日 AI 使用量 / 全站上限、各用户用量与剩余额度、邀请码状态。

## 换 AI 供应商

见 README「切换 AI 供应商」：只需改 `API_BASE_URL` / `MODEL_NAME` / `API_KEY` 三个环境变量或 Secret。
